01 — Introducción

¿Qué es el juego?

El Juego de Estrategia en Tablero es un juego de turnos para dos jugadores desarrollado en consola. Se juega sobre una matriz de 8×8 casillas utilizando tres tipos de piezas: Rey, Torre y Soldado.

El objetivo es capturar el Rey del oponente o eliminar todas sus piezas antes de que él haga lo mismo contigo.

02 — Inicio de sesión

Acceso al sistema

Antes de ingresar al menú, el sistema solicita credenciales de acceso. Estas están definidas dentro del programa.

1
Ingresa el usuario Escribe el nombre de usuario y presiona Enter.
2
Ingresa la contraseña La contraseña se muestra con asteriscos (*) por seguridad. Presiona Enter al terminar.
3
Acceso concedido Si las credenciales son correctas, el sistema te lleva al menú principal automáticamente.
⚠️
Intentos fallidos El sistema permite un máximo de 3 intentos. Si los 3 fallan, el programa se cierra automáticamente.

05 — Piezas

Tipos de piezas

Cada jugador inicia con 7 piezas: 1 Rey, 2 Torres y 4 Soldados.

R / r
Rey
Se mueve 1 casilla en cualquier dirección: horizontal, vertical o diagonal. Es la pieza más importante — si lo capturan, pierdes.
T / t
Torre
Se mueve en línea recta (horizontal o vertical) cualquier número de casillas. No puede saltar sobre otras piezas.
S / s
Soldado
Avanza 1 casilla hacia adelante. Ataca en diagonal. No puede retroceder. Blancas suben, Negras bajan.
06 — Movimiento

Cómo mover piezas

En cada turno el sistema indica de quién es el turno. Debes ingresar la casilla de origen y la casilla de destino usando el formato LetraNúmero.

Turno de: Jugador 1 (Blanco)
Puntaje: 0

Origen (ej. A1): E1
Destino (ej. A2): E2
1
Escribe la casilla de origen Indica dónde está la pieza que quieres mover (ej. E1).
2
Presiona Enter El sistema pide la casilla de destino.
3
Escribe la casilla de destino Indica a dónde quieres mover la pieza (ej. E2).
4
El sistema valida y ejecuta Si el movimiento es válido, el tablero se actualiza. Si no, muestra un error y pide el movimiento de nuevo.

Capturas

Si mueves tu pieza a una casilla ocupada por una pieza rival, la capturas automáticamente. El sistema muestra un mensaje con los puntos ganados.

♟️
Condición de victoria El juego termina cuando capturas el Rey del oponente, o cuando eliminas todas sus piezas. El sistema declara al ganador automáticamente.
07 — Puntaje

Sistema de puntuación

Los puntos se acumulan automáticamente al capturar piezas del rival durante la partida.

Pieza capturadaPuntos
Soldado10 puntos
Torre10 puntos
Rey60 puntos (10 + 50 adicionales)

Al finalizar la partida, el puntaje del ganador se compara con el récord actual. Si es mayor, se actualiza automáticamente. Para consultar el puntaje más alto usa la opción 3 del menú.
