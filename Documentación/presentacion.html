CÓMO SE INGRESA

El jugador escribe coordenadas tipo B4 para origen y destino.

PARSEO

// "B4" → fila 4, col 1
col = letra - 'A';
fila = 8 - numero;

LEYENDA

Mayúsculas = Blancas
Minúsculas = Negras
. . = Casilla vacía

04 — Las piezas

Reglas de movimiento

R
Rey
1 casilla en cualquier dirección: horizontal, vertical o diagonal. La pieza más importante.
1 por jugador
T
Torre
Se mueve en línea recta cualquier número de casillas. No puede saltar otras piezas.
2 por jugador
S
Soldado
Avanza 1 casilla hacia adelante. Ataca en diagonal. No puede retroceder.
4 por jugador

POLIMORFISMO EN ACCIÓN

// Tablero llama al método sin saber qué tipo de pieza es
if (pieza.MovimientoValido(filaD, colD, matriz))
    EjecutarMovimiento(); // cada clase implementa sus propias reglas

07 — Puntaje

Sistema de puntuación

TABLA DE PUNTOS

Soldado capturado +10
Torre capturada +10
Rey capturado +60

10 base + 50 adicionales

CÓMO SE CALCULA

public void SumarPuntos(Pieza p) {
  Puntaje += 10;
  if (p is Rey)
    Puntaje += 50;
}

RÉCORD

Al terminar la partida el puntaje se compara con el récord. Solo se actualiza si es mayor. Si son iguales, se mantiene el primero.
